## Phase 0 — Foundation
- Confirm product requirements
- Repository and documentation baseline
- Architecture
- Database model
- Authentication and RBAC
- Environments and deployment foundation

## Phase 1 — Smart OPD Core
- Patient registration/profile
- Doctor schedules
- Real-time slots
- Online booking
- Booking confirmation
- Walk-in flow
- Reception check-in
- Queue/token
- Doctor live queue
- Patient Ready event
- Patient 360 foundation
- Consultation
- Prescription foundation
- Notifications
- Admin
- Audit logs

## Phase 2 — Connected Care
- Lab
- Pharmacy
- Billing
- Documents
- Follow-up
- Payments
- Messaging
- Telemedicine

## Phase 3 — Interoperability
- ABHA/ABDM integration
- FHIR exchange
- External lab/healthcare interfaces
- Consent workflows

## Phase 4 — Intelligence
- AI documentation assistance
- Summaries
- Operational analytics
- Wait-time analytics
- No-show insights

## Phase 5 — Scale
- Multi-location
- Enterprise controls
- Partner APIs
- Developer ecosystem

## Release gate

Do not move a phase to production based on UI completion alone. Require end-to-end workflow tests, authorization/security review, deployment verification, monitoring and documentation.
